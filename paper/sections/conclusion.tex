\section{Conclusion}
\label{sec:conclusion}

We presented \FenceDD{}, a verified C library that provides proved numerical
guarantees for double-double arithmetic on successful return. Our Rocq
analysis extends prior results from unbounded exponents to IEEE\~754,
preserving relative bounds for addition and deriving mixed relative and
absolute bounds for multiplication and division. Using VST, we prove that the
C kernels implement the analyzed algorithms and that successful runtime checks
establish the conditions required by the numerical theorems.

In generated tests, observed errors approached the proved bounds, QD rarely
returned results satisfying the corresponding numerical properties for inputs
that caused \FenceDD{} to return a failure status, and the runtime checks added
$2.5$--$11$ nanoseconds per call. These results show that proved guarantees for
double-double arithmetic can be provided through ordinary C functions at
modest absolute cost.
